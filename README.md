# رتل — نسخة الويب الأولية

واجهة PWA عربية RTL باتجاه «موجة الليل». هذه بداية تنفيذ للواجهة والتنقل، وليست إصدارًا جاهزًا للنشر.

## التشغيل

تجربة النشر المقصودة على GitHub Pages: https://k4rim93.github.io/rattil-app/ . افتح الرابط في Safari على iPhone، ثم اختر **مشاركة ← إضافة إلى الشاشة الرئيسية**.

للتشغيل محليًا، استخدم خادم HTTP من مجلد المشروع. افتح الآيفون والكمبيوتر على شبكة Wi‑Fi نفسها واستخدم عنوان الكمبيوتر، وليس `127.0.0.1`.

## ما يعمل الآن

- تنقل بين اليوم، المصحف، الرئيسية، التسميع، التقدم، والإعدادات.
- تبديل وضعي «اتبعني» و«المراجعة» في واجهة التسميع.
- تحكم تجريبي بتغيير الصفحة والعلامة المرجعية.
- تبديل السمة وحفظها محليًا.
- تخزين واجهة التطبيق الأساسية للعمل دون اتصال بعد أول زيارة.

## ما يحتاج توصيلًا قبل الاستخدام الحقيقي

- مواقيت صلاة مرتبطة بموقع المستخدم وطريقة حساب يختارها.
- مصدر مصحف وصفحات/خط مرخّص ومراجع؛ الصفحة الحالية معاينة، والنص فيها مثال وليست صفحة مصحف معتمدة.
- فهرس القرآن ومزامنة موضع القراءة.
- محرك تعرف محلي للتلاوة، محدد موضع، ومحاذاة كلمات؛ أزرار التسميع تعرض رسالة صريحة ولا تفتح الميكروفون.
- اختبار PWA على iPhone 15 Pro Max وiOS 27، خصوصًا إذن الميكروفون وذاكرة النموذج والعمل دون اتصال.

لا توجد خدمة سحابية أو API أو حساب مطلوب في هذه النسخة. خطوط العرض تُختار من خطوط النظام لتبقى الواجهة مستقلة عن الشبكة.
